### Featured project

**[SRS–Code Drift Detector](https://github.com/canhwindy/srs-code-drift-detector)**: an AI agent system that checks every
pull request against the Software Requirements Specification. It retrieves the affected requirements from a LightRAG
knowledge graph, generates end-to-end tests from the SRS, tags each requirement as matching, mismatch or missing,
and flags code behaviour the SRS does not describe. Findings go to a dashboard where analysts approve or reject them.
